# StockSage 真实数据获取规范与统一数据契约 v1.0

决策日期：2026-11-05。面向本科课程实现。**这份文档是当前真实数据入口的规范**；原计划书中的大规模数据和高级分析是后续扩展。校验实现见 [`contracts.py`](../stocksage/contracts.py)，实际可运行样本见 [`data/real_sample/`](../data/real_sample/)，获取调研依据见[来源调研](./数据来源调研.md)。

## 1. 项目究竟研究什么

用明确的证券标识，把“某公司有哪些报道、报道在什么时候可用”与“该股票每天的行情”连接起来，形成可追溯的图谱和特征，再比较加入新闻前后的简单预测模型。**先证明数据能被正确解释和处理，再讨论预测是否有用。**

### 固定范围

| 项目 | 正式课程实验建议 | 本次已经落地的小批验收 |
|---|---|---|
| 市场/币种 | 中国大陆沪深 A 股，人民币 | 相同；沪深两所各一只 |
| 行业/证券 | 白酒一个行业，5 只；贵州茅台 `600519.SH`、五粮液 `000858.SZ`、泸州老窖 `000568.SZ`、洋河股份 `002304.SZ`、古井贡酒 `000596.SZ` | 茅台、五粮液；方便核验和演示，不代表全行业 |
| 行情区间 | 固定为 2025-01-01 至 2025-12-31；不滚动改变样本终点 | 2025-01-01 至 2025-04-30；实际行情从 01-02 起，两只各 78 行 |
| 新闻区间 | 同期公开中文公司资讯；按来源记录真实覆盖程度 | 人工选取 5 篇，2025-02-06 至 04-29；仅标题、链接、时间与证据摘录 |
| 粒度 | 每证券每实际有行情交易日一行；不用分钟和逐笔 | 相同 |
| 预测 | 收盘信息获得后，估计下一有行情交易日的收盘价收益率 | 三个现有模型原样运行，仅作管线验收 |
| 新闻地域 | 以“是否明确涉及样本公司”为准 | 相同；公司在海外经营的报道仍可纳入 |

选白酒是因为公司名称、业务和公开报道较易人工核验，并非认为该行业更容易赚钱。固定名单有便利抽样和幸存者偏差，结论不外推全市场。首版不接入港美股、北交所、B 股、ETF、跨币种、自动交易或分钟行情；宏观政策和行业文章先作为补充材料，**没有明确公司证据就不强行分配到每只股票**。

5 只股票和全年新闻尚未采集完成。建议的全年范围是下一阶段目标，不是本次已经拥有的数据。正式实验可以先人工核验 100—200 篇；不足时报告实际数量，不补造新闻，也不承诺新闻覆盖完整。第一版六个特征只需预热 5 个交易日，跳过这些日期；事件研究及其额外估计窗口暂不纳入。

## 2. 初学者先理解这几件事

- **证券和公司不同**：本文的公司是主体，`600519.SH` 是它在上海交易所交易的证券。六位代码必须当字符串保存，不能丢掉五粮液的前导零。
- **行情是日线**：开盘、最高、最低、收盘价均为元/股；成交量统一为股。`1 手 = 100 股`，成交额才是元，两者不能混用。
- **复权是调整历史价格**：现金分红等会造成股价机械变化。直接对未复权价格求收益，容易把除息缺口当成下跌。本样本用采集时的前复权固定快照；它不是当天屏幕上的原始成交价，也不是完整的含分红总回报。
- **报道不是事实标签**：媒体、公司公告、评论、自动财报快讯要区分；报道可能有偏向、延迟或后续更正。正文缺失必须留空，不能让模型补写。
- **没有收集到新闻，不等于没有新闻**：本次绝大多数日期新闻数为零，只说明这 5 条记录中没有该日信息。
- **新闻情绪不等于涨跌原因**：现有中文关键词词典很简单。新闻和价格同日变化仅是观察，不能输出“该新闻导致上涨”。

## 3. 先收什么、暂缓什么

| 数据 | 当前必需 | 可选/以后再做 |
|---|---|---|
| 证券主表 | 代码、公司全称、交易所、币种、行业、别名、来源 | 历史更名、母子公司关系、历史行业归属 |
| 行情 | 交易日、OHLC、成交股数、复权口径、抓取时刻、原始快照引用 | 成交额、换手率、指数收益、市值 |
| 资讯 | 标题、原文链接、来源、时间及精度、内容类型、证券关联和证据 | 授权正文、转载聚类、完整更新版本、自动实体抽取 |
| 交易日 | 独立的市场开市日列表、来源及范围 | 官方停复牌明细、临时休市 |
| 审计 | 数据集版本、文件哈希、采集记录、质量报告 | 定时采集、数据库增量与完整断点续传 |

首版不收集 Level-2 订单簿、复杂财务因子、机构一致预期、供应链图、社交媒体全量舆情。它们并非项目成立的前提。尤其不要把财报中的“报告期截止日”当成财报的“公开日”。

## 4. 文件布局、编码和版本

```text
data/real_sample/
  metadata.json       # 版本、单位、来源口径、覆盖范围、SHA256
  stocks.csv          # 证券主数据
  prices.csv          # 规范日线
  news.csv            # 规范资讯
  calendar.csv        # 实际开市日期；SH/SZ 分开标识
  raw/manifest.json   # 请求 URL、采集时间、响应/摘录文件哈希
  raw/*.json          # 原始行情响应；新闻只留页面元数据与必要证据摘录
```

使用 UTF-8，CSV 支持 BOM、必须有表头；正文和标题含逗号时使用标准 CSV 引号。列表用 `|`；不使用字符串 `null`、`NaN` 或 `None` 表示未知。数值必需项不允许空；新闻 `body`、`first_seen_at`、`updated_at` 可为空字符串。未知事件用 `未分类`，不能臆测。

`metadata.contract_version="1.0"` 启用严格真实契约。声明 `synthetic=false` 必须使用 v1。旧 demo 格式仍可导入；缺少真实标记的旧 CSV 标记为“真实性未确认”，不能因此获得真实数据认证。新增信息性列可保留；改变字段含义、单位或时序语义时应升级契约版本，不能静默兼容。

### metadata.json 必需字段

| 字段 | 类型/固定值 | 解释 |
|---|---|---|
| `contract_version`, `dataset_id`, `label` | 字符串；版本 `1.0` | 数据集唯一名称、可读标签；修改快照应另建数据目录与 ID |
| `synthetic` | 布尔 `false` | 表示提供者声明是真实来源；不是真实性的数学证明 |
| `timezone`, `currency`, `volume_unit` | `Asia/Shanghai`, `CNY`, `share` | 时间、价格币种、成交量单位 |
| `price_basis` | `unadjusted` / `qfq_snapshot` / `hfq_snapshot` | 一个数据集只使用一种口径；前/后复权均为固定采集快照 |
| `adjustment_asof` | 含时区时间；未复权可空 | 复权快照的采集截止时刻，不谎称是供应商的历史基准日 |
| `news_time_mode` | `historical_assumption` / `observed` | 历史发布时间假设，或实际观察；同一数据集不可混用 |
| `calendar_basis` | `official_sessions` / `index_observed_sessions` | 交易所日历，或指数实际行情日代理；不得混称 |
| `coverage` | 对象，`start`、`end` 均为日期 | 接受的资讯发布日期、行情和日历的闭区间 |
| `usage_notes` | 非空文本 | 来源使用限制；公开可读与获得分发许可不是一回事 |
| `sha256` | 相对路径→64 位小写十六进制哈希 | 覆盖四张 CSV 及全部 `raw_ref`；本身不能包含自身递归哈希 |

样本还保留 `selection` 和 `news_completeness=curated_incomplete`。哈希用于发现文件变动，不能证明第三方页面从未改写。新闻的 `response_sha256` 只记录获取时整页响应指纹；整页 HTML 未随样本分发，**可离线核验的是保留的元数据摘录，不是完整原文历史版本**。

## 5. 四张表的数据字典

除注明可空外均必需。日期固定 `YYYY-MM-DD`，精确时间使用 ISO 8601 且含 `+08:00` 或 `Z`/其他合法偏移；处理时统一上海时区。URL 必须是可解释的 HTTP(S) 来源链接。

### stocks.csv：一行一只证券

| 字段 | 类型 | 定义 |
|---|---|---|
| `symbol` | 字符串主键 | 六位代码加 `.SH`/`.SZ`；必须与 exchange 一致 |
| `company` | 非空文本 | 上市公司全称；当前人工核验，不做自动消歧 |
| `industry`, `industry_scheme` | 文本 | 本次为 `白酒`、`course_manual_v1`；课程自定义行业，不能当申万/证监会代码 |
| `aliases` | `|` 分隔文本，可空 | 已确认简称；当前仅保留，不自动关联子公司或品牌 |
| `exchange`, `currency`, `security_type` | 枚举 | `SH`/`SZ`、`CNY`、`A_SHARE` |
| `source_url`, `fetched_at` | URL、时间 | 主数据参考来源和实际核验/采集时刻 |

当前行业只用于静态展示，不进入预测；没有历史有效期的主数据不能解释为当时已知的动态行业成分。

### prices.csv：一行一只股票的一个有行情交易日

| 字段 | 类型 | 定义 |
|---|---|---|
| `symbol`, `date` | 联合主键 | 已登记证券与交易日，不能重复 |
| `open`, `high`, `low`, `close` | 正有限数值 | 同一复权口径的元/股，必须 `low <= open/close <= high` |
| `volume` | 非负整数股数 | 零成交与缺失不同；不把缺失补为 0，不按复权比例调整股数 |
| `source`, `source_url` | 文本、URL | 实际供应商及本次请求；不把 AKShare 工具名冒充原始数据机构 |
| `fetched_at` | 时间 | 本次实际收到响应的时刻，不能写成历史交易日；完整日线不得早于当日收盘，复权快照不得晚于 adjustment_asof |
| `price_basis` | 枚举 | 必须与 metadata 一致，禁止拼接不同复权口径 |
| `raw_ref` | 相对路径 | 本行来源的行情 JSON，须在 metadata 哈希清单中 |

本样本直接解析腾讯 JSON，原始排列是 `日期,开,收,高,低,成交手数`，转换成当前 CSV 的 `开,高,低,收`，成交手数乘 100。**如果以后使用已经输出“股”的 AKShare 新版函数，不可再乘 100**。保留原始价格精度，不统一粗暴四舍五入为两位。单只股票至少 30 个交易日是当前代码运行下限，不是有效实验样本量要求。

### news.csv：一行一篇规范记录

| 字段 | 类型 | 定义 |
|---|---|---|
| `id` | 非空唯一字符串 | 样本为 `NEWS-` 加规范链接 SHA256 前 16 位；同一链接当前只留一个版本 |
| `title`, `body` | 非空标题、可空正文 | 原始标题；正文无授权或未提取就留空，不把摘要假称全文 |
| `source`, `url` | 文本、URL | 当前发布平台及可核对的页面来源；转载时保留原来源名称 |
| `document_type` | 枚举 | `media_report`、`company_announcement`、`commentary`、`automated_report`；不是事件类型 |
| `text_kind` | 枚举 | `title_only`、`excerpt`、`licensed_fulltext`；只有全文经确认可使用才标最后一种 |
| `published_at` | 日期或时间 | 网页明确给出的发布时刻，不从 URL、财报期末日或搜索排名推测 |
| `published_precision` | `second`/`minute`/`date` | 日期精度时 published_at 只存日期；分钟精度时秒填 `00` 并显式保留精度 |
| `available_at` | 含时区时间 | 管线统一使用的可用时间；推算方法见下一节 |
| `availability_basis` | 同 news_time_mode | 清楚标记是真实观察还是历史假设 |
| `first_seen_at` | 时间，可空 | 我们首次收到**该内容版本**的时刻；历史回填未知必须留空 |
| `fetched_at` | 时间 | 本次实际抓取时间，历史回填时通常远晚于发布日期 |
| `updated_at` | 时间，可空 | 来源明确提供的版本更新时间；未知不等于从未更新 |
| `symbols` | `|` 分隔字符串列表 | 至少一个已登记证券；多公司文只保留一条新闻并列出多只证券 |
| `link_method`, `link_evidence` | `manual_verified`、非空文本 | 当前人工确认关联，证据必须明确支持公司身份；模糊命中先不导入 |
| `event_type`, `event_evidence` | 枚举、证据文本 | 事件由标题或极短原文摘录支持；未分类时证据可空 |
| `content_sha256` | 64 位哈希 | `SHA256(标题.strip() + 换行 + 正文.strip())`，UTF-8；不包含人工事件证据 |
| `raw_ref` | 相对路径 | 新闻页面元数据/必要证据摘录文件；须登记 SHA256 |

事件固定词表：`业绩`、`分红`、`回购`、`股东增减持`、`订单`、`研发`、`政策`、`并购`、`诉讼处罚`、`项目`、`管理层`、`产品经营`、`其他`、`未分类`。这是事件主题，不是“利好/利空”的人工标签；“拟回购”不代表回购已完成，原始标题/证据须保留该区别。计划、传闻、被否认等细分状态后续另增字段，当前不作量化推断。

当前不接收同一 URL 的多个更新版本，以免新版正文被错误放回旧时点；发现更新应先保留独立原始快照并人工决定可用版本。未来需要 `(article_id, version_id)` 的新契约。相同规范 URL 或相同标题正文哈希在一批内会被拒绝；采集前去掉跟踪参数、统一重定向后的规范 URL，再合并证券列表。**语义相近的跨站转载不会被自动识别**，正式实验还需要人工去重/转载分组。

### calendar.csv：一行一个交易所的一个开市日

必需字段为 `exchange,date,source,source_url,fetched_at,raw_ref`，类型与前述一致；联合主键 `(exchange,date)`。只列开市日；不以“周一至周五”冒充交易日。

当前样本由腾讯沪深300 `sh000300` 的实际行情日期生成 SH/SZ 两份开市代理，能识别春节和清明休市并与个股日期交叉检查，但不能发现指数和股票同时缺失、个股停牌或官方临时休市记录。正式研究应改用交易所日历/经核验的交易日历服务，并相应设置 `official_sessions`。

## 6. 时间规则：哪些信息可以进入哪一天

沿用现有管线：每只证券的日线构成 15:00 收盘序列，新闻进入第一个满足 `available_at <= 当日15:00` 的桶。恰好 15:00 进入当天；晚 1 秒、周末、节假日都进入后续第一个实际有行情的收盘桶；超过样本最后收盘的资讯列为 pending，不能进入预测或证据图。

收盘桶只是日频信息切分。预测实际执行在日线已经收到之后；15:00 不代表系统能零延迟拿到完整行情，不能据此声称可在当天收盘成交。当前文件不记录历史日线接收时间，历史行情与新闻均不满足完整的逐时点可交易数据要求。

两种时间模式分别建数据集：

1. **当前历史回填** `historical_assumption`：first_seen_at 留空；秒精度用给定时刻，分钟精度用该分钟结束的下一分钟，日期精度用次日 00:00。available_at 固定为该精度上界 **加 5 分钟**。5 分钟只是保守工程假设，不是已测得传播延迟，也不能证明页面当年存在或版本未变化。
2. **将来实际观测** `observed`：采集该版本的 first_seen_at，available_at 不早于 first_seen_at、发布精度上界和已知 updated_at，且不晚于 fetched_at；发现新版要重新处理版本，不能只继承旧版的 first_seen_at。当前采集命令专用于历史回填，不是连续实时采集服务。

例如：2025-04-25 周五 22:56:19 的五粮液报道，假设可用为 23:01:19，进入 04-28；2025-04-29 17:53:21 的茅台报道进入 04-30。只有 `2025-04-25` 日期的文章，保守可用为 04-26 00:05，也不会混进周五收盘。

预测目标仍是 `close[next_observed_session] / close[t] - 1`，特征和标签只由价格序列计算，新闻用词典计算情绪与数量。缺少个股行情时不插值、不前向补齐；质量报告列出缺少的市场日期。如果跨停牌/源缺失形成多日标签，应在正式单日实验前剔除相应标签或更换已核实完整的区间；本小样本没有这种缺口。已有 5 个交易日预热及时间顺序回测协议保持不变。

## 7. 质量和采集失败怎么处理

导入整批拒绝：缺必需列、未知证券、重复键、无时区时间、可用时间早于信息、非法 OHLC、NaN/无穷、负成交量、非整数股数、混合复权口径、日期不在日历/覆盖范围、新闻哈希不符、快照哈希不符或引用越出数据目录。不会偷偷丢掉坏行然后继续。

质量报告保留实际行数、每证券日期区间、新闻数、已对齐/待对齐数、缺失市场日期、时间口径分布及局限说明。`passed_with_notes` 代表结构通过但有用途限制；不代表新闻完整、关系抽取正确、全部时间无前视偏差或来源许可已确认。来源单位等语义仍需人工核对。

采集命令目前只处理固定小批：单次请求 25 秒超时，网络临时失败/429/5xx 最多 3 次有限退避重试，请求之间间隔 0.5 秒；403/404 立即失败，不绕过限制。原始响应先写快照、哈希校验后转换；目标目录非空即拒绝，不覆盖旧实验。失败后保留部分原始文件供检查，**尚未实现自动增量和断点续抓**，改用新目录重新采集。离线重放不访问网络；线上刷新因复权重算可能不同，不应覆盖固定实验快照。

## 8. 当前实现、复现与验收

```powershell
# 不访问网络：使用仓库里的固定真实快照跑完整管线
```
