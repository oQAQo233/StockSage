# 实验与复现说明

## 当前真实运行的协议

现在支持两类独立输入：下面的默认合成 demo，以及[固定真实小样本](../data/real_sample/)；真实样本的用途、字段与时间假设见[统一数据契约](./统一数据契约.md)，实测结果见[真实数据验收](./真实数据验收.md)。两类输入使用相同六特征和模型，不混合训练。

默认样本：三只虚构股票、各 110 个工作日、固定种子 `20261105`。生成器在随机价格变化中加入前一日合成事件的弱信号，专门用于验证融合流程。未模拟节假日、公司行动、市场共同冲击、交易费用或完整新闻传播过程。

预测发生在交易日 t 收盘后，使用截至该次 15:00 收盘的信息；目标为下一有行情交易日的收盘收益率。当前精确收盘时刻的信息假定即时可用，正式项目需设置可观测延迟。收盘后 t→t+1 收益率目标不等于下一日开盘才入场可获得的收益。

## 六个特征

新闻知识模块已接入，默认 CSV 经 newskg 去重与抽取，外部正文可显式替换新闻输入。候选关系用于证据展示，当前未加入六维预测特征。正文替换可能改变词典情绪，比较实验需固定同一快照与时间口径。见[整合与实测](./新闻知识模块整合与实测.md)。

| 索引 | 特征 | 定义 |
|---|---|---|
| 0 | 日收益率 | `close[t]/close[t-1]-1` |
| 1 | 三日收益率 | `close[t]/close[t-3]-1` |
| 2 | 五日波动率 | 最近 5 个日收益率的总体标准差 |
| 3 | 成交量比 | `volume[t]/mean(volume[t-5:t])-1`；历史均值为零时记 0 |
| 4 | 新闻情绪 | 本次收盘桶新闻的词典分数均值，无新闻时为 0 |
| 5 | 新闻数量 | 收盘桶中关联该股票的新闻条数 |

每条新闻情绪分数为 `(正面关键词次数-负面关键词次数)/max(关键词总次数,1)`。标题与正文一起计算，不理解否定、反讽、传闻、影响对象等语义；对多主体新闻只能给出共享简化分数。新闻数量特征可区分“无新闻”和部分中性新闻情形。

跳过前 5 个交易日作为预热。最后一行特征没有标签，用于最新预测，不进入有标签训练集。

## 模型与回测

- 零收益基线：恒预测 0。
- 纯行情：前 4 个特征的岭回归。
- 新闻融合：全部 6 个特征的岭回归；当前没有图结构特征。
- α 固定为 8，最小化 `Σ(y - ŷ)² + 8 × Σβ²`，截距不受惩罚。参数没有依据测试集选择。
- 初始训练长度为有标签样本数的 60%（至少 15 条），剩余样本逐日扩展窗口回测。
- 对每一次预测，标准化均值/标准差仅从该训练窗口计算；零方差缩放值取 1。
- 训练行日期严格早于本次特征日期，训练标签最晚可以落在本次收盘日，因为预测是在该日收盘后发出。
- 当前逐股票建模；正式的多股票共享模型需按全局日期切分。
- 最新预测使用所有已知标签与最后一行特征。

## 指标解释

MAE/RMSE 以收益率单位计算，网页按百分数展示。方向准确率只在真实收益非零时计算；预测为零视为未命中。该定义导致零收益基线方向命中为 0，故方向指标不能单独衡量模型好坏。三个模型使用完全相同测试日期。

界面中的“历史误差尺度”是融合模型测试窗口 RMSE，不是经过覆盖率校准的预测区间。特征贡献是最新标准化特征乘回归系数，加上截距后等于估计收益率；不能理解成新闻造成价格变化的百分比。

## 复现与验证

```powershell
python run.py --no-server
python -m unittest discover -s tests -v
```

默认数据与预测在同一 Python 版本上可复现；报告的生成时间会变化。JSON 保留逐次预测、训练数据截止日和标签截止日，可人工核对时序。SQLite 保留原始规范数据及派生报告。

自动化测试重点覆盖：盘后/周末/时区对齐、末日待对齐、修改未来数据不改变历史特征和预测、贡献求和、非法输入拒绝、真实格式 CSV 重加载、数据库持久化、HTTP 端点。它们验证实现逻辑，不验证真实金融预测有效性。

真实数据质量与时间可用性说明；训练/验证/测试日期；实体、事件、情绪人工评估；行情/情绪/数量/事件/图谱特征消融；多股票和不同市场阶段的结果；重复新闻与来源偏差讨论；失败样本分析。若只是合成数据，应将结论限定为系统功能与实验协议可运行。
