## 3. 为什么没有直接承诺两年的全部新闻

历史股票日线相对容易获取；难点是**有合法正文、明确主体、可靠发布时间、历史版本且覆盖连续的新闻库**。最近资讯接口解决不了完整历史覆盖，搜索引擎样本也不能证明完整。收费服务若没有实际账号权限，无法从网页文档推断本项目能获取哪些字段。

适合目前团队的路线是：历史固定快照用于关联分析和系统演示；后续开始按固定频率积累实际接收日志；若需要严格历史预测，先评估有版本/可用时间记录的授权数据，再扩大研究结论。即使开始实时采集，也不能补回从未记录的历史首次接收时间。

前复权历史价格也会因之后的分红变化。固定快照可复现实验，但其 `adjustment_asof` 晚于研究期；和历史新闻回填一样，应在报告中限制为回顾性验证。日历也只取指数有行情日作为代理，正式研究要补官方日历与停牌信息。

## 4. 面向本科实现的后续采集步骤

1. 先冻结当前版本和本文样本，完成本次链路验收。
2. 将相同契约扩展到建议的 5 家公司、2025 年全年，逐家公司核对证券名称、量价单位和公司行动；不要根据预测好坏增删公司。
3. 先制定公司名/代码/简称检索式与固定来源清单，再搜历史资讯；记录查询与失败。对同源转载合并，所有样本人工核验关联，保留被拒绝原因。不得用“找到多少”假称“全部”。
4. 追加公告、人工标签、官方日历前先评估成本；不要同时引入复杂财务指标和跨市场新闻。
5. 只有覆盖、来源和时间限制说清楚后，才用固定时间切分比较模型；融合没有提升也应如实报告。

没有购买服务、注册账户、发送消息或运行后台定时任务。本次没有使用付费/授权全文数据，公开来源的商用及再分发许可仍需在相应用途发生前核实。
