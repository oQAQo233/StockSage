## 4. 模型实测值及解释

下表是固定小样本上的管线产物，收益率误差乘 100 后以百分数展示。每只股票均使用相同的 29 个测试预测时点；跨股票合计 58 行并不意味着有 58 个独立测试日期。

| 证券 | 模型 | MAE | RMSE |
|---|---|---:|---:|
| 茅台 | 零收益 | 0.856% | 1.330% |
| 茅台 | 纯行情岭回归 | 1.076% | 1.760% |
| 茅台 | 行情＋新闻岭回归 | 1.053% | 1.728% |
| 五粮液 | 零收益 | 0.927% | 1.313% |
| 五粮液 | 纯行情岭回归 | 1.100% | 1.545% |
| 五粮液 | 行情＋新闻岭回归 | 1.111% | 1.553% |

**两只股票的融合模型误差均高于零收益基线。**不能挑出茅台融合模型相对纯行情的微小变化就声称“新闻有效”。没有依据这个样本调参或更换证券来美化结果。

现有词典只在茅台的最后一行得到一个非零情绪，该行还没有下一日标签；五粮液所有标题的词典情绪均为零。因此这个样本连“情绪是否有预测贡献”都不具备合适的评估条件。保留当前词典是为了证明接线与缺省行为，不把金融文本理解的任务假装已经解决。

## 5. 复现

```powershell
python run.py --data-dir data/real_sample --output-dir output/real_sample --no-server
python -m stocksage.collect --replay data/real_sample/raw --output-dir output/replayed_real
python -m unittest discover -s tests -v

# 网页展示
python run.py --data-dir data/real_sample --output-dir output/real_sample
```

实际执行使用 Python 3.12.14；项目要求 Python 3.10+。若系统没有 python 命令，可用 `py -3` 或启动脚本的 `-Python` 参数指定解释器。

输出目录包含 `report.json`、`stocksage.sqlite3`、`quality_report.json`、`aligned_news.csv`、`features.csv`。报告生成时间会改变；固定输入的分析/预测可复现。原始快照文件和 CSV 的指纹记录在 metadata 与 raw manifest 中。

自动测试共 **18 项通过**：保留原有 10 项 demo/时序/HTTP 测试，新增 8 项真实快照、时间资格、来源持久化、股数换算、节假日、离线重放、异常拒绝与哈希测试。网页另核对真实标签、复权价格标记、股票切换、新闻来源链接与证据节点。
