# 新闻知识模块独立化验收

2026-11-08：已将原新闻知识子项目中主流程使用的实现及资源迁入 StockSage，替换了前一轮的外部源码动态加载。**移除原 `knowlegde_merge` 目录后，主项目仍能独立运行当前实验及交互图谱。**原目录暂留作历史参考，不参与运行。

## 已落地的位置

| 职责 | 主项目实现 | 接入流程的位置 |

| 国内财经、RSS、GDELT、Guardian、离线样例发现 | [sources/](../stocksage/news_knowledge/sources/) | 来源发现、窗口筛选与限流 |

| 环境参数 | [config.py](../stocksage/news_knowledge/config.py)、[环境模板](../.env.example) | 从主项目根目录读取环境配置；兼容 NEWSKG_* 参数 |

移除了运行时的 `VENDOR_ROOT`、独立命名空间、`spec_from_file_location` 和 `legacy_module` 加载链，改为正常相对导入。可选的正文、联网、LLM、KGGen、PyVis 依赖仍按需加载。默认 CSV + rule 和关闭抽取的 none 模式只需标准库。

主项目已有的 [pipeline.py](../stocksage/pipeline.py)、[storage.py](../stocksage/storage.py)、[fusion.py](../stocksage/fusion.py)、[forecast.py](../stocksage/forecast.py) 继续承担统一编排、SQLite、时间对齐与预测，未再引入原子项目的另一套 CLI、pipeline 或数据库。原独立实验脚本的命令不属于主项目运行接口。

迁移时还修正了两处失败状态：KGGen 生成异常、LLM 返回非法 JSON/缺少关系列表时会显式失败，不再误记为“成功但抽取 0 条”。`fixtures` 显式从本地读取合成 HTML，避免请求示例 URL。

## 如何证明能够独立运行

[verify_standalone.py](../tools/verify_standalone.py) 将主包、入口、配置、测试及数据复制到临时目录，**不复制原子项目**，然后在新的 Python 进程中运行。它不重命名或删除用户的目录，也不复用正在运行的网页进程。

```powershell
.venv/Scripts/python.exe tools/verify_standalone.py
```

实际结果写入 [verification.json](../output/standalone_validation_20261108/verification.json)，所有阶段通过：

1. `python -I -S` 执行当前真实 CSV + rule 完整实验，关闭 site-packages，确认默认流程不依赖已安装的可选包。
2. `python -I -S` 执行相同数据 + none，确认关闭抽取后去重也已独立。
3. 使用内置 PyVis 入口生成离线 HTML。
4. 在副本中执行全部 **42 项测试，全部通过**，没有跳过当前真实样本或可视化检查。
5. 逐证券比较迁移前后的行情、新闻、特征、预测、摘要、知识候选和图谱节点/边/三元组，**全部相同**；仅引擎标识、说明等元信息改为主项目实现。

测试包含实际本地 HTTP 正文抓取、原转换器清洗、哈希快照重放、内置冻结语料、离线样例、规则关系落库、图谱 API、可选 LLM 本地协议、后端错误和未来信息隔离。实时外部发现源已迁入，但此次没有逐个重新请求所有上游，也未调用真实云端 LLM/KGGen。

## 当前真实数据结果

- 数据集：新能源 3 股，宁德时代、比亚迪、亿纬锂能。
- 行情：2026-07-01—2026-11-06，每股 87 条，共 261 条；沿用上一轮真实采集原始快照，此次没有重新下载或用旧白酒样本替代。
- 新闻：15 篇，合计 16 条证券关联。
- 合并交互图：46 个节点、52 条边。
- 候选三元组：**0 条**。52 条边是证券主数据及新闻提及/报道/来源结构关联，并非 52 条抽取事实。
- 新闻历史可用时间仍明确采用 `historical_assumption`，用于回顾性课程实验。

冻结旧语料仅用于回归验证，不进入此次新能源数据的结果。独立化改变代码归属和依赖路径，不会提升关系抽取质量，也不会改变既有数值实验结果。

## 日常运行入口

```powershell
# 当前真实数据完整实验与网页；端口占用时换一个空闲端口
.venv/Scripts/python.exe run.py --data-dir data/fresh_energy_20261108 --output-dir output/fresh_energy_native_20261108 --port 8768

# 内置可视化入口
.venv/Scripts/python.exe -m stocksage.visualization --report output/fresh_energy_native_20261108/report.json --out output/fresh_energy_native_20261108/graph_interactive.html

# 全部回归检查
.venv/Scripts/python.exe -m unittest discover -s tests -v
```

页面侧栏“可拖拽图谱”访问同一快照的 `/graph/interactive`，可加 `?symbol=300750.SZ` 筛选。默认实验不需要第三方包；交互图谱需要 PyVis，联网正文需要 [requirements-news.txt](../requirements-news.txt)，KGGen 需要额外安装 kg-gen 并配置模型服务。
