# 2026年世界数码及AI排名出炉 香港三项指标摘全球第一

中新社香港11月11日电 (记者 戴小橦)国际管理发展学院(IMD)11日发布《2026年世界数码及人工智能排名》(下称“排名”)。榜单涵盖全球70个经济体，香港位列全球第十一名、亚洲第四名。

据悉，本年度排名新增多项人工智能(AI)评估指标。排名以治理、科技与基础设施、效率、劳动力发展、价值观五大因素为核心，下设15个子因素、共计88项细化指标。数据回溯显示，2022年至2025年间，香港在该系列排名中的位置介于第九位至第十六位。

香港在本次排名中整体表现亮眼，多项指标跻身全球前十名。其中，劳动力发展位列全球第二，效率排名全球第五，科技与基础设施位居全球第十。在细分子因素中，香港的技术框架、行业做法、教育与培训三项指标获评全球第一，人才、社会取态、监管框架亦跻身全球前十。

特区政府发言人表示，排名肯定香港在数码和人工智能发展方面是全球最具竞争力的经济体之一。特区政府正循香港第一个五年规划提出的方向，全力推动香港发展成为国际创科中心。

香港资讯科技商会荣誉会长方保侨认为，排名肯定了香港数码及人工智能发展的综合实力。技术框架、行业做法、教育与培训拿下全球第一，显示香港在人才培育、科研基础、企业应用上的扎实根基。他预期，在特区政府推进“AI+行动”、加码算力建设等举措带动下，香港有望把现有优势进一步转化为实实在在的经济和社会效益。(完)
