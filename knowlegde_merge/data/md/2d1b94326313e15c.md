专题：全球网络峰会 Web Summit Lisbon 2026

11月10日，小鹏汇天CEO赵德力发布微博称，相信未来十年全球将迎来飞行汽车高速发展时期。2026 web summit 中国企业阵容空前，扛起了世界先进科技的大旗。

Web Summit于11月9-12日在葡萄牙里斯本举行。这场全球科技盛会汇聚来自全球7万名参与者，覆盖157个国家和地区。今年，50多位中国演讲嘉宾集结，MiniMax、宇树、智元、小米、腾讯、Manus等登台，展示中国AI与机器人创新力量。
