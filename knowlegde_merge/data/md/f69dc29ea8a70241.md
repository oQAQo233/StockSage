# 香港国际眼镜展云集逾600家展商 AI眼镜吸引海外买家

中新网香港11月4日电 (记者 张语洽)第34届香港国际眼镜展4日在香港会议展览中心开幕。展览以“睛彩新视野”为主题，汇聚来自14个国家和地区的逾600家展商。

展会设有乐龄产品、智能眼镜及绿色方案3个主题标签，人工智能(AI)眼镜产品成为关注焦点之一。来自法国的眼镜零售商克里斯特尔(Christelle)在一家中国内地AI眼镜品牌展位前体验多款新产品。她接受中新网记者采访时表示，中国在AI领域发展迅速，她看好AI眼镜的行业前景，希望在客户需求大规模增长前持续关注相关行业动态。

李未可科技有限公司带来全新AI记忆眼镜，产品配备音频设备及可拆分磁吸摄像头，可拍摄记录影像及资料，再由AI提炼图文信息，适配日常办公场景。该公司海外市场营销负责人邓芸介绍，这是公司第二年参展，目前重点拓展海外市场，已针对不同市场优化AI功能并启动前置测试。她表示，AI眼镜涉及录音、录像、数据采集，各地法规要求不尽相同，希望借助香港开展隐私及数据合规方面的法律咨询，为产品进入海外市场作准备。

香港特区政府政制及内地事务局副局长胡健民当天致辞表示，香港具备市场经济、自由贸易、资金与人才自由流动等方面优势，将继续发挥联通东西方的作用，为有意出海的内地与香港企业，以及希望开拓内地市场的海外品牌提供专业服务。(完)
